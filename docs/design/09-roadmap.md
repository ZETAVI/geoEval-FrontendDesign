# 09 · 复盘与推进路线（光感构成）

## 复盘
| 维度 | 现状 | 问题 / 结论 |
|---|---|---|
| 视觉语言 | 光感构成：色场卡 + 讲业务含义的 SVG 插画 + 克制动效 | 方向已确认，保持此设计精度 |
| 插画 | 旧透镜 / 纸飞机使用负偏移溢出卡片，与标题、徽标错位 | 插画统一放入卡片内固定槽位（右上 w-36/40），标题限宽 60% |
| 诊断图形 | 透镜含义模糊 | 改为「放大镜逐行搜索 AI 回答，命中品牌行高亮 + 5 平台依次点亮」`SearchArt` |
| 背景 | 两条色带，偏简单 | 改为 Logo 拆解动态场 `LogoField`：新月自转、透光丝带摆动、橙点巡游并发出信号波纹、雷达轨道与扫描扇区、指针视差 |
| 品牌 | 顶栏为临时圆点 | 统一 `LogoMark`，与背景同源几何 |
| Figma Motion | 只读 MCP，无法创作；用户决定不等待 | 动效直接在代码（motion）中实现，`figma-motion-handoff.md` 仅作参考 |
| 文案规则 | 卡片标题空泛、有设计黑话 | 标题 2–6 字（动词+宾语或功能名），说明 1 句 ≤20 字且写明具体动作 |
| 指标口径 | 推荐你的平台 / 提到你的平台 / 提到你的回答，含义重叠 | 只记录排位，不判断“是否推荐”；靠前(≤3) / 居中(4–5) / 靠后(≥6) / 未提及表示推荐程度 |
| Make Kit | hardcoded-astra-ui 无 npm 元数据，无法安装 | 继续使用 global.css `--s-*` token |

## 组件选型原则（调研吸收）
- **结论先行、证据可追溯**（shapeof.ai / Perplexity 引用模式）：报告 = 一句话结论 → 四项指标 → 问题行 / 排位图 → 原文高亮。
- **排位图而非热力矩阵**：热力格会挤压文本；改为泳道 + 横轴排位的点图，位置即推荐程度，每点即证据入口（见 11-diagnosis）。
- **可解释门槛**：锁定操作点击后说明原因与补救（Stripe Dashboard 的 inline explanation）。
- **分段暴露**：Tabs + 共享布局指示器（Vercel / Radix Tabs 语义）。
- **高风险操作**：Sheet + 摘要 + 二次确认（发布、充值）。
