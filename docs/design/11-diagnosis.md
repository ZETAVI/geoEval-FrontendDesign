# 11 · AI 搜索诊断模块规格

## 业务
对一个品牌向 5 个 AI 平台各问 4 个问题，得到 20 条回答；记录品牌是否出现及其在回答品牌列表里的排位。同一版品牌资料只能诊断一次。

## 数据模型（`src/design/diag.ts`）
| 导出 | 含义 |
|---|---|
| `BRAND` | 当前品牌名 |
| `QUESTIONS[{text, kind}]` | 4 个问题；`kind`: `find`（找品牌）/`ask`（问到你，Q3 直接问品牌名） |
| `PLATFORM_NAMES` | 豆包、腾讯元宝、DeepSeek、通义千问、文心一言（顺序即数据行、列头、头像点的顺序；窄处用 `PLATFORM_SHORT`） |
| `SAMPLES[平台][问题] = {rank|null, total, note?}` | 20 条采样；`rank` = 品牌在回答列表中的名次，`total` = 列出的品牌数 |
| `tierOf(rank)` / `TIER` | 档位与视觉编码（靠前/居中/靠后/未提及） |
| `answerList(sample)` | 还原回答里的品牌列表（其他品牌为模拟） |
| `METRICS` | `mentionRate, platformsHit, avgRank, topCount, findRate(主动提及率), askHits…` |
| `bestRank(p)`, `questionHits(q)` | 派生查询 |
接真实接口时保持这些形状，替换数据源即可。

## 页面与组件
| 页面 | 文件 | 要点 |
|---|---|---|
| 诊断进行中 | `Running.tsx` | 5×4 格子逐格 等待→提问中→结果；环形进度 n/20；“已提到你 n 条”；刚收到动态（aria-live）；完成通知开关；完成后横幅进入报告；可重播 |
| 诊断报告 | `Report.tsx` | Hero（指数+4 指标）→ tabs：概览 / 平台排位 / 品牌印象；重新诊断门槛 popover |
| 平台排位 | `PositionMap.tsx` | 左：4 问题全文列表（点选聚焦）；右：5 条泳道排位图，横轴第 1–8 位 + 未提及区；下：证据面板（品牌列表原文，默认只露前三家和你，可展开） |
| 品牌印象 | `Impression.tsx` | Portrait（一句话画像，关键词内嵌高亮）、Cloud（字号=频次，点开看原句）、Peers（气泡面积=出现次数） |

## 可视化选择理由
- **排位图而非热力矩阵**：位置本身就是“推荐程度”，横向靠左=更早被提到；泳道天然按平台聚合，不需要塞文本。
- **迷你图形配指标**：提及率=华夫格(20 格)、平台覆盖=5 点、平均排位=刻度尺、主动提及率=分段条。
- **印象用语言型呈现**：画像句子 + 词云 + 原句，避免进度条。

## 交互链路
概览问题行 → `openQuestion(q)`：切到平台排位 tab，聚焦该问题并选中首个命中 → 圆点点击 → 证据面板（Evidence）。
首页 Diagnosis 卡 CTA → 报告；进行中完成 → 报告；报告优化方向 → 回首页（待改为直达内容/发布）。
