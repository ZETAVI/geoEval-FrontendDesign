# 06 · AI 结果呈现

参考 shapeof.ai 的模式分类：可追溯（Evidence）、过程可见（Progress）、可修正（Regenerate）、边界说明（Disclaimers）。诊断模块的完整口径见 [11-diagnosis.md](11-diagnosis.md)。

## 核心口径（2026-10 校正）
我们**只记录品牌在 AI 回答列表里的排位**，不解析、不声称“AI 推荐了你”。推荐程度由排位推出：靠前(≤3) / 居中(4–5) / 靠后(≥6) / 未提及。所有界面避免“推荐你的平台 / 推荐率”这类暗示已判断推荐的措辞。

## 报告的结构（概览 + 两个深入 tab）
1. **结论 Hero**：综合指数 + 一句话结论 + 四个互相区分的指标（提及率、平台覆盖、平均排位、主动提及率），每个指标配一个迷你图形。指数旁有“怎么算”说明入口。
2. **概览 tab**：4 个问题一行一个（全文可读，5 个平台的排位一眼看完）→ 印象与同场品牌两张预览卡（点进印象 tab）→ 优化方向（≤2 张，结构“问题 / 依据 / 做法 / 去处”）。
3. **平台排位 tab**：问题列表 + 排位图（横轴=排位）+ 单条回答证据面板。
4. **品牌印象 tab**：一句话画像（AI 生成）+ 关键词云（点开看原句）+ 同场品牌气泡。

## 规则
- **证据优先**：任何结论两次点击内可追溯到原始回答。概览问题行 → 平台排位 tab（已定位到该问题）→ 点圆点 → 原始回答。
- **不做保证**：固定边界说明“反映本次采样中 AI 的回答，不代表长期或保证性结果”，caption 字号，放在结论旁和证据面板底部，不做弹窗。
- **直接问 ≠ 主动出现**：问题分“找品牌”（用户不知道你）与“问到你”（直接问品牌名）。直接问品牌名的命中不能代表被发现的能力，因此单独给“主动提及率”。
- **过程透明**：诊断进行中展示 5×4 真实格子逐格揭晓（见 Running.tsx），可离开并开启完成通知。
- **人工确认**：AI 生成文章必须用户确认后才能下单，确认按钮前显示将锁定的版本信息。
- **AI 内容标识**：“AI 生成”小标签 + 服务色竖线，不用紫色渐变或闪光图标。
- **失败要诚实**：样本不足写“本轮证据不足，暂未形成品牌印象”，不编造。
- **一次诊断一版资料**：同一版品牌资料只诊断一次，“重新诊断”默认锁定并说明原因与补救入口。
