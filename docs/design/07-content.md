# 07 · 文案与格式

## 语气
面向中小商家老板：平实、具体、带动词。称呼用户为“你”，主语是品牌。

## 卡片标题与说明（硬约束）
- **标题**：2–6 字，动词+宾语（`完善文章`、`选择发布方式`）或具体功能名（`平台排位`、`印象关键词`）。
- **说明**：1 句，≤20 字，说明一个具体业务动作或用户得到的好处。写“做什么 / 得到什么”，不写“是什么理念”。
- 好：`自动保存变更`、`看 AI 怎么介绍你的品牌`、`20 条回答里有你的比例`。
- 坏：`AI 如何看待青禾家政`、`动作与回应`、`获取更多服务能力`。

## 禁用词
赋能、全链路、闭环、流转、信息密度、智能化、一站式、深度洞察、价值最大化、解锁、助力。
内部设计黑话（“信息密度”“动作与回应”）同样禁止出现在 UI 与组件注释之外的任何用户可见文本里。

## 指标命名（全站统一）
| 用户看到的名字 | 含义 | 说明文案 |
|---|---|---|
| 提及率 | 20 条回答中提到你的比例 | 20 条回答里有你的比例 |
| 平台覆盖 | 5 个平台中至少提到你一次的数量 | 提到你的平台数量 |
| 平均排位 | 被提到时的平均名次 | 提到你时排第几 |
| 主动提及率 | 没点你名字的问题里被提到的比例 | 没点你名字时提到你 |
| 靠前 / 居中 / 靠后 / 未提及 | 排位档位 | 见 02-tokens |
禁用旧名：推荐你的平台、提到你的平台、提到你的回答。

## 错误信息（发生了什么 · 影响什么 · 你能做什么）
> 支付结果还在确认中。积分到账前不能用于下单。通常 1 分钟内完成，你可以先去做别的事，到账后会通知你。
禁止“操作失败”“系统错误”，不暴露错误码或服务商名称。

## 按钮
动词 + 对象：`开始诊断`、`确认文章`、`查看报告`。危险操作写后果：`确认并支付 1,200 ⚡`。

## 数字与时间
- 积分 `1,200 ⚡`；金额 `¥300`（整数元）；指数 `3.5 / 5`（1 位小数）；排位 `第 3 位`；比例 `30%`。数字 `tabular-nums`。
- 24 小时内相对时间，更早 `9月28日 14:20`，跨年加年份，北京时间。
